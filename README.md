# Tabula HR Analytics Dashboard

## Overview

The **Tabula HR Analytics Dashboard** is an interactive Tableau dashboard designed to analyze employee attrition, workforce demographics, job satisfaction, and department-level HR trends. This project helps HR teams and business stakeholders make data-driven decisions by visualizing key workforce insights.

## Key Features

* Employee attrition analysis by gender and age group
* Department-wise attrition tracking
* Education field-wise employee analysis
* Job satisfaction rating insights
* KPI summary dashboard
* Employee distribution by age group
* Interactive Tableau visualizations and filters

## Dashboard Insights

The dashboard provides insights into:

* Attrition trends across departments
* Gender-based workforce distribution
* Employee satisfaction levels
* Age group demographics
* HR performance KPIs

## Tools & Technologies

* **Tableau** – Data visualization and dashboard creation
* **Microsoft Excel** – Data source management
* **GitHub** – Version control and project sharing

## Dataset

The dashboard uses HR employee data stored in Excel format.

Example fields include:

* Employee Age
* Gender
* Department
* Education Field
* Job Satisfaction
* Attrition Status

## How to Use

1. Download or clone this repository.
2. Open the `.twb` file in Tableau Desktop.
3. Ensure the Excel data source path is connected correctly.
4. Explore the interactive dashboard.
